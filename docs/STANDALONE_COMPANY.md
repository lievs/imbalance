# WMS для отдельной компании

Эта ветка — самостоятельная серверная версия WMS. Она должна работать с
отдельной базой данных и отдельным доменом и не подключается к действующей
WMS первой компании.

## Состав версии

Сохранены складские разделы: номенклатура, склады и ячейки, приемка,
размещение, перемещения, инвентаризация, короба, отчеты и план отгрузок.

Не подключаются:

- производство и заказы на производство;
- выработка и планы сотрудников (события выработки также не записываются);
- обмен с 1С;
- API Ozon и Wildberries.
- отдельный раздел «МВБ Логистика».

Добавлен раздел `Подбор коробов`. В задании видны склад и актуальное
размещение каждого короба (ряд или ячейка). Сотрудник сканирует подобранные
короба, а после последнего короба задание закрывается автоматически.

## Размещение на отдельном сервере

Использовать ветку `codex/standalone-company-wms` и отдельные значения:

- `WMS_DATABASE_URL` — новая база PostgreSQL;
- `WMS_SECRET_KEY` — новый случайный ключ;
- `WMS_PUBLIC_URL` — новый домен;
- `WMS_BEHIND_PROXY=1`;
- `WMS_FORCE_SECURE_COOKIES=1` после включения HTTPS.

Нельзя подключать эту версию к базе действующей компании. Таблицы для
заданий подбора создаются при первом запуске автоматически.

Для установки нужны IP/домен сервера, SSH-пользователь, способ авторизации
(ключ предпочтительнее пароля) и реквизиты новой базы PostgreSQL.
